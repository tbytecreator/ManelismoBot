# Bot do Manelismo

## Objetivos

Criar um bot que responda como o Manoel Alves Ferreira Neto quando questionado sobre as questões mais importantes da humanidade.

## Referencias

Manoel Alves Ferreira Neto é o autor do canal do Youtube TByteCreator e participava dos primeiros episódios do podcast Podtrash, dos irmãos Bruno Gunter e Douglas Frickie. Antes disso ele criou diversos blogs. Segue como referência para pesquisa da pesonalidade do Manoel Neto os seguintes links:

<https://diariodobabaca.blogspot.com/>
<https://www.youtube.com/@tbytecreator>
<https://td1p.com/>
<https://www.facebook.com/tremyen/?locale=nb_NO>
<https://td1p.com/podtrash-22-fica-frio-e-de-baunilha/>
<https://www.youtube.com/watch?v=8yN3AnNqE4U>

Alem dos links adicionados, faça uma pesquisa intensa sobre tudo que o Manoel Alves Ferreira Neto publicou na internet, usando os nicknames Tremyen e TByteCreator

## Defininições Tecnicas

- O Backend deve ser escrito em RUST
- O Frontend deve ser Web usando Node.js e React para uma interface responsiva
- O Sistema deve estar encapsulado em um container Docker
- O Sistema deve ser documentado com um read.me que ensine a pegar e levantar o container Docker
- Toda a documentação do sistema deve estar em uma pasta chamada "docs"
- Documente toda a arquitetura do sistema.
